# Screencast: "The Replan Path Nobody Tested" (LLMCompiler)

Answer a question that needs two independent lookups and a sum. Run the
lookups in parallel. Recover when one lookup fails.

## The Original

LangGraph's LLMCompiler tutorial (462 code lines, 2 nodes, 1 conditional
edge) streams a DAG of tool tasks with `$N` dependency references, schedules
them by hand as dependencies resolve, and asks a "joiner" LLM to choose
between a final answer and `Replan`. Routing is encoded in message types:
`should_continue` ends the graph when the last message is an `AIMessage`.
Four issues report the replan branch as broken or untested:
[#274](https://github.com/langchain-ai/langgraph/issues/274) (multiple
dependencies in one argument), [#1459](https://github.com/langchain-ai/langgraph/issues/1459),
[#1513](https://github.com/langchain-ai/langgraph/issues/1513),
[#1565](https://github.com/langchain-ai/langgraph/issues/1565).

## The Contrast

**before.py** — a condensed, hermetic version of that control flow: planner,
task-fetching unit with a `$N` resolver and thread pool, joiner, replan via a
`SystemMessage` the planner must parse, `recursion_limit` as the safety net.

**after.py** — the tool tasks are `ActionSpec`s whose dependencies are
preconditions. A* orders them, `executor="parallel"` runs the two lookups in
one wave, and the sum waits for both. No dependency parser, no joiner.

**after_disrupted.py** — the fast index fails for one city or for every
city: the observer blacklists the failed lookup, the planner swaps in the
archive lookup, and a sibling result already obtained is kept. With both the
index and the archive down the run ends with `no_plan` and an explanation.

## Notebook

[`llm_compiler_screencast.ipynb`](llm_compiler_screencast.ipynb) runs all
three scripts with narration and executed output cells. It is generated by
`_build_notebook.py` so it cannot drift from the scripts:

```bash
uv run python examples/screencast/llm_compiler/_build_notebook.py
uv run --with nbconvert jupyter nbconvert --to notebook --execute --inplace \
    examples/screencast/llm_compiler/llm_compiler_screencast.ipynb
```

## Run

```bash
cd LangGOAP
uv run python examples/screencast/llm_compiler/before.py
uv run python examples/screencast/llm_compiler/after.py
uv run python examples/screencast/llm_compiler/after_disrupted.py
```
