# Screencast: "Find the Dead Branch" (weather disaster management)

Grade a forecast, brief the right department, get a human to sign off on
mild alerts, send the alert, survive the relay and the operator saying no.

## The Original

[`NirDiamant/GenAI_Agents`](https://github.com/NirDiamant/GenAI_Agents) →
[`Weather_Disaster_Management_AI_AGENT.ipynb`](https://github.com/NirDiamant/GenAI_Agents/blob/main/all_agents_tutorials/Weather_Disaster_Management_AI_AGENT.ipynb),
Part 1 ("Real-Data Agent Graph"). The notebook (1,049 code lines across both
parts; 21 `add_node`, 4 `add_conditional_edges`, 17 `add_edge`; the graph and
its two routers are each defined twice) fetches OpenWeatherMap data, asks a
local LLM to name a disaster type and grade its severity, logs, routes to one
department with `route_response`, asks a human (blocking `input()`) for
low/medium alerts and auto-approves the rest, then sends an e-mail or runs
`handle_no_approval`.

Three things the routing hides:

- `route_response`'s first branch is `return "emergency_response"` followed
  by a bare `"send_email_alert"` string: a second target was evidently
  intended and is unreachable. The return annotation still lists it.
- `get_human_verification` auto-approves anything that is not `"low"` or
  `"medium"`, so when the severity call fails ("Assessment Failed") during a
  hurricane the event is routed to civil defense and e-mailed with no human
  in the loop.
- `send_email_alert` wraps `smtplib` in `try/except`, appends the error to
  `messages`, and the graph ends as if the alert had gone out. "No immediate
  threat" is routed to civil defense and e-mailed too.

## The Contrast

**before.py** — a condensed, hermetic version: the same nodes and edges, the
two routers verbatim (dead literal included), the same `try/except`; the
API, the LLM, `input()` and SMTP are fixtures and flags.

**after.py** — a `FunctionalSensor` grades the forecast once and writes
facts (`threat`, `severe`, `flood_or_storm`, and `approved` when severe).
Eight `ActionSpec`s: three departments chosen by preconditions,
`approve_alert` with `require_human_approval=True`, `send_email_alert` with
an `ActionQos` that retries connection errors, `send_sms_alert` as the dearer
fallback, `withhold_alert` and `log_all_clear`. The goal is
`forecast_handled`. A `FunctionalStuckHandler` relaxes the goal to
`decision_logged` when the operator has denied the alert.

**after_disrupted.py** — the operator denies the alert (the action fails, is
blacklisted, no path to the goal remains, the stuck handler relaxes it and
`withhold_alert` runs with the operator's reason); the SMTP connection drops
once (retried inside the action, no re-plan); the relay rejects the message
outright (the action fails, is blacklisted, and `send_sms_alert` is the next
cheapest route).

| | Hand-wired (`before.py`) | GOAP (`after.py`) |
|---|---|---|
| Which department | `route_response` string matching, one dead branch | preconditions on `severe` / `flood_or_storm` |
| Who needs a human | `if severity in ["low", "medium"]` inside a node, auto-approve otherwise | `approve_alert` precondition `severe: False`; policy is one line in the sensor |
| Human says no | `verify_approval_router` → `handle_no_approval` | action failure → stuck handler relaxes the goal → `withhold_alert` |
| Relay down | `try/except`, message appended, graph ends | `ActionQos` retry, then blacklist and SMS fallback |
| No threat | routed to civil defense and e-mailed | `log_all_clear` |

## Notebook

[`weather_alert_screencast.ipynb`](weather_alert_screencast.ipynb) runs all
three scripts with narration and executed output cells. It is generated by
`_build_notebook.py` so it cannot drift from the scripts:

```bash
uv run python examples/screencast/weather_alert/_build_notebook.py
uv run --with nbconvert jupyter nbconvert --to notebook --execute --inplace \
    examples/screencast/weather_alert/weather_alert_screencast.ipynb
```

## Run

```bash
cd LangGOAP
uv run python examples/screencast/weather_alert/before.py
uv run python examples/screencast/weather_alert/after.py
uv run python examples/screencast/weather_alert/after_disrupted.py
```
